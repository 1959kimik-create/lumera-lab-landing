# Google Apps Script 업데이트 방법

## 1. 코드 붙여넣기

1. Google Sheets > **확장 프로그램 > Apps Script**
2. `Code.gs` 전체 교체 후 **저장**

## 2. 이메일 권한 승인 (중요)

시트 저장은 되는데 메일만 안 오면 **권한 미승인**인 경우가 많습니다.

1. Apps Script 편집기 상단 함수 선택: **testAdminEmail**
2. **실행(▶)** 클릭
3. **권한 검토 > 고급 > 이동 > 허용**
4. `1959.kimik@gmail.com` 수신함 확인 (스팸함 포함)

## 3. 새 버전 재배포 (필수)

1. **배포 > 배포 관리 > 연필 > 새 버전 > 배포**
2. Web App URL은 기존과 동일

## 4. 확인

- 문의 제출 후 시트 `email_status` 열에 `SENT` 표시
- 실패 시 `FAILED: ...` 사유 표시

## 5. 배포 설정 확인

| 항목 | 값 |
|------|-----|
| 실행 주체 | 나 |
| 액세스 권한 | 모든 사용자 |
